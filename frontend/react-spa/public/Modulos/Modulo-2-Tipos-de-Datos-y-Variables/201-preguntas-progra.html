⚙️ Ejercicios de Programación: Tipos de Datos Primitivos

Ejercicio 1: Medidor de Peso (Operador sizeof)

Instrucción: Escribe un programa que utilice el operador sizeof() para imprimir el tamaño en bytes de los cuatro tipos primitivos principales: char, int, float y double.

Solución en C:

C

#include <stdio.h>

int main(void) {

printf("--- TAMAÑOS EN BYTES ---\n");

printf("Tamaño de char: %zu bytes\n", sizeof(char));

printf("Tamaño de int: %zu bytes\n", sizeof(int));

printf("Tamaño de float: %zu bytes\n", sizeof(float));

printf("Tamaño de double: %zu bytes\n", sizeof(double));

return 0;

}

Salida Esperada (Típica en sistemas de 64 bits):

--- TAMAÑOS EN BYTES ---

Tamaño de char: 1 bytes

Tamaño de int: 4 bytes

Tamaño de float: 4 bytes

Tamaño de double: 8 bytes

Ejercicio 2: ASCII Básico (Char como Número)

Instrucción: Declara una variable char llamada letra_A e inicialízala con el valor 'A'. Imprime esta variable dos veces: la primera como carácter (%c) y la segunda como número entero decimal (%d) para mostrar su código ASCII.

Solución en C:

C

#include <stdio.h>

int main(void) {

char letra_A = 'A';

printf("El carácter es: %c\n", letra_A);

printf("Su valor ASCII es: %d\n", letra_A);

return 0;

}

Salida Esperada:

El carácter es: A

Su valor ASCII es: 65

Ejercicio 3: Declaración y Uso Mixto

Instrucción: Declara e inicializa tres variables: una edad (int), un promedio (float) y el símbolo de moneda (char). Imprime los tres valores en una sola línea de forma descriptiva.

Solución en C:

C

#include <stdio.h>

int main(void) {

int edad = 28;

float promedio_final = 8.75f;

char simbolo_moneda = '$';

printf("Perfil: %c%d de edad con promedio de %.2f.\n",

simbolo_moneda, edad, promedio_final);

return 0;

}

Salida Esperada:

Perfil: $28 de edad con promedio de 8.75.

Ejercicio 4: Diferenciando Precisión (double)

Instrucción: Declara una variable de tipo double para almacenar una versión muy precisa de PI. Imprime el valor utilizando el especificador de formato de punto flotante (%f) y luego utiliza %.10f para demostrar que el double puede almacenar más de 6 decimales con exactitud.

Solución en C:

C

#include <stdio.h>

int main(void) {

double pi_preciso = 3.1415926535;

printf("PI con precisión estándar (6 decimales): %.6f\n", pi_preciso);

printf("PI con alta precisión (10 decimales): %.10f\n", pi_preciso);

return 0;

}

Salida Esperada:

PI con precisión estándar (6 decimales): 3.141593

PI con alta precisión (10 decimales): 3.1415926535

Ejercicio 5: Declaración Explícita de float

Instrucción: Declara una variable float llamada altura y asígnale el valor 1.85. Asegúrate de usar el sufijo f para indicarle al compilador que es un float y no un double. Imprime el valor.

Solución en C:

C

#include <stdio.h>

int main(void) {

// Es crucial usar 'f' para evitar una advertencia de conversión,

// ya que 1.85 sin sufijo es un double por defecto en C.

float altura = 1.85f;

printf("Mi altura es: %.2f metros\n", altura);

return 0;

}

Salida Esperada:

Mi altura es: 1.85 metros

Ejercicio 6: Aritmética de Caracteres ASCII

Instrucción: Declara una variable char con la letra 'J'. Súmale el valor 5 a esa variable y luego imprime el resultado como carácter para encontrar la letra resultante en la secuencia ASCII.

Solución en C:

C

#include <stdio.h>

int main(void) {

char letra_inicial = 'J';

// Se suma 5 al código ASCII de 'J' (74 + 5 = 79).

char letra_final = letra_inicial + 5;

printf("La letra inicial es: %c\n", letra_inicial);

printf("La letra resultante es: %c\n", letra_final);

return 0;

}

Salida Esperada:

La letra inicial es: J

La letra resultante es: O

Ejercicio 7: Rango Básico de Enteros

Instrucción: Declara dos variables int: una llamada saldo con un valor positivo (15000) y otra llamada gasto con un valor negativo (-3500). Imprime ambos valores.

Solución en C:

C

#include <stdio.h>

int main(void) {

int saldo = 15000;

int gasto = -3500;

printf("Saldo de la cuenta: %d\n", saldo);

printf("Gasto registrado: %d\n", gasto);

return 0;

}

Salida Esperada:

Saldo de la cuenta: 15000

Gasto registrado: -3500

Ejercicio 8: Asignación de int desde float (Truncamiento)

Instrucción: Declara una variable float llamada pi_decimal con el valor 3.14159f. Luego, declara una variable int llamada pi_entero y asigna el valor de pi_decimal a pi_entero. Imprime el valor de pi_entero para demostrar la pérdida de la parte decimal (truncamiento).

Solución en C:

C

#include <stdio.h>

int main(void) {

float pi_decimal = 3.14159f;

// Al asignar un float a un int, C trunca (corta) la parte decimal.

int pi_entero = pi_decimal;

printf("Valor original: %.5f\n", pi_decimal);

printf("Valor entero después de la asignación: %d\n", pi_entero);

return 0;

}

Salida Esperada:

Valor original: 3.14159

Valor entero después de la asignación: 3

Ejercicio 9: Impresión de Carácter con Comillas Dobles

Instrucción: Usa solo una llamada a printf() para mostrar el nombre de un tipo primitivo y el carácter que utiliza para su delimitación, incluyendo comillas dobles en la salida.

Solución en C:

C

#include <stdio.h>

int main(void) {

// Usamos el carácter de escape para comillas dobles (\" para el texto)

// y el carácter de escape para comillas simples (\' para el char, aunque \' no es estrictamente necesario, es más claro).

printf("El tipo \"char\" usa el delimitador \'\' para sus valores.\n");

return 0;

}

Salida Esperada:

El tipo "char" usa el delimitador '' para sus valores.

Ejercicio 10: Declaración Múltiple en una Línea

Instrucción: Declara e inicializa tres variables de tipo int (huespedes, dias, precio) en una sola línea de código. Luego calcula el costo total en una cuarta variable int e imprime el resultado.

Solución en C:

C

#include <stdio.h>

int main(void) {

// Declaración múltiple: Separamos cada variable con coma.

int huespedes = 4, dias = 3, precio = 50;

int costo_total = huespedes * dias * precio;

printf("El costo total de la reserva es: %d\n", costo_total);

return 0;

}

Salida Esperada:

El costo total de la reserva es: 600
