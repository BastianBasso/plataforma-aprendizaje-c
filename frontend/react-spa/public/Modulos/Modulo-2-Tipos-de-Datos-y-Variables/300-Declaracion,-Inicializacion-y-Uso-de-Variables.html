3. Declaración, Inicialización y Uso de Variables

Declaración de Variables 🏷️

La Declaración de una variable es el primer paso y el más fundamental para usar datos en tu programa C. Es el acto de informarle al compilador que vas a necesitar un espacio en la memoria RAM para almacenar una pieza de información de un tipo específico.

Sintaxis y Propósito

La sintaxis para declarar una variable es siempre la misma: se especifica primero el Tipo de Dato, seguido por el Nombre que usarás para referirte a esa ubicación de memoria.

Sintaxis: tipo_de_dato nombre_de_variable;

Elemento Ejemplo Propósito
Tipo de Dato int, float, char Le indica al compilador cuántos bytes reservar (ej. 4 bytes para int).
Nombre contador, precio, inicial Proporciona la etiqueta legible que usarás en tu código.

Ejemplos de Declaración:

C

1int contador; // Declara una variable entera llamada contador.
2float precio; // Declara una variable de punto flotante.
3char inicial; // Declara una variable para un solo carácter.

El Rol de la Declaración

Es crucial entender lo que hace y lo que no hace una declaración:

  1. Reserva de Espacio (SÍ): Cuando declaras int contador;, el compilador reserva el número de bytes necesarios (típicamente 4) en la memoria RAM.

  2. Definición de Valor (NO): La declaración por sí sola no asigna un valor útil a esa ubicación de memoria. Simplemente reserva el espacio.

En este punto, la variable existe en la memoria, pero contiene un valor indeterminado (o "valor basura"), que es lo que queda de programas anteriores en esa celda de la RAM. La asignación del primer valor se aborda en el siguiente tema: la Inicialización.

Inicialización de Variables 🎯

La Inicialización es el proceso de asignar el primer valor útil a una variable declarada. Es el paso que sigue a la declaración (reservar el espacio) y es crucial para evitar el uso de valores basura.

El Operador de Asignación (=)

El operador clave para la inicialización (y reasignación posterior) es el operador de asignación (=).

  • En C, el símbolo = no significa "igual a" (como en matemáticas), sino que significa "asigna el valor de la derecha a la variable de la izquierda".

Métodos de Inicialización

Existen dos formas principales de inicializar variables en C:

  1. Declaración y Asignación por Separado (Dos Pasos):

Primero se reserva el espacio (declaración), y en una línea posterior, se le da un valor por primera vez (inicialización).

C

int cantidad; // 1. Declaración (reserva 4 bytes)

cantidad = 50; // 2. Inicialización (asigna el valor 50)

  1. Inicialización Directa (Un Solo Paso):

Es el método más seguro y recomendado. La declaración y la asignación del primer valor se hacen en la misma línea.

C

int edad = 25; // Declara e inicializa la edad a 25.

float temperatura = 36.5f; // Declara e inicializa la temperatura.

char codigo = 'P'; // Declara e inicializa el carácter.

Método Ventaja Principal
Separado Útil cuando el valor inicial depende de una lógica posterior en el programa.
Directo (Recomendado) Evita los valores basura (ver próximo subtema) y mejora la legibilidad.

Siempre debes asegurarte de que una variable esté inicializada antes de usar su valor.

Variables sin Inicializar (Valores Basura)

Una de las características más críticas (y a veces peligrosas) de C es su enfoque en la eficiencia y el control de bajo nivel. Esto nos lleva al concepto de valores basura.

¿Qué son los Valores Basura?

Cuando tú declaras una variable, el compilador reserva un bloque de bytes en la memoria RAM, pero no limpia ni sobrescribe esos bytes automáticamente.

  • Definición: El valor basura (garbage value) es el dato impredecible, aleatorio y sin sentido que ya existía previamente en la dirección de memoria asignada a tu nueva variable. Es, literalmente, lo que dejó el último programa que utilizó ese espacio.

  • Advertencia Crucial: C asume que, como programador, tú eres responsable de inicializar la variable antes de leer su valor. Si intentas usar una variable que solo ha sido declarada, tu programa utilizará este valor basura, lo que puede llevar a resultados erróneos o a un comportamiento impredecible.

Ejemplo Empírico en C

El siguiente código demuestra el problema del valor basura. Nota que la variable valor_basura se declara, pero nunca se le asigna un valor antes de ser impresa.

C

1#include <stdio.h>
2int main(void) {
3 // 1. Declaración: El espacio para esta variable se reserva en la RAM.
4 int valor_basura;
5 // 2. USO PELIGROSO: Intentamos leer la variable sin inicializar.
6 printf("El valor basura es (impredecible): %d\n", valor_basura);
7 // 3. Demostración de un comportamiento seguro
8 int valor_seguro = 10;
9 printf("El valor seguro es: %d\n", valor_seguro);
10 return 0;
11}

Salida Típica (Resultado Impredecible):

El valor basura es (impredecible): -1073741824

El valor seguro es: 10

Nota: La salida del valor basura (-1073741824 en este ejemplo) cambiará cada vez que se ejecute el programa en diferentes máquinas o incluso en diferentes momentos en la misma máquina. Este comportamiento aleatorio es la razón por la que siempre debes inicializar tus variables al declararlas.

Uso y Reasignación de Variables

Una vez que una variable ha sido declarada e inicializada, podemos interactuar con ella de dos maneras fundamentales: usando su valor (leyéndolo) o cambiando su valor (reasignándolo).

1. Uso (Acceso) del Valor

Para acceder al valor almacenado en una variable, simplemente utilizamos su nombre en cualquier expresión o sentencia.

El nombre de la variable actúa como un marcador de posición para el valor que contiene.

  • En la Salida (printf): Usamos el nombre para mostrar el valor al usuario.

  • En Operaciones: Usamos el nombre para realizar cálculos con ese valor.

C

1#include <stdio.h>
2
3int main(void) {
4 int saldo = 100; // Inicialización
5 int descuento = 20;
6
7 // Uso del valor: el nombre 'saldo' se reemplaza por el valor 100 en la impresión.
8 printf("Saldo inicial: %d\n", saldo);
9
10 // Uso del valor: el nombre 'saldo' y 'descuento' se usan en una operación.
11 int nuevo_saldo = saldo - descuento;
12 printf("Nuevo saldo: %d\n", nuevo_saldo);
13
14 return 0;
15}

2. Reasignación del Valor

La clave del término variable es que su valor puede variar durante la ejecución del programa. La reasignación es el proceso de cambiar el valor de una variable existente, y se realiza nuevamente con el operador de asignación (=).

Cuando reasignas un valor:

  1. La expresión a la derecha del = se evalúa primero.

  2. El resultado se almacena en la ubicación de memoria de la variable a la izquierda del =.

  3. El valor anterior de la variable se sobrescribe y se pierde.

Ejemplo de Reasignación:

C

1#include <stdio.h>
2int main(void) {
3 int contador = 1; // Inicialización
4 printf("Contador (Inicio): %d\n", contador);
5 // Reasignación 1: Cambia el valor a 5.
6
7 contador = 5;
8 printf("Contador (Primer cambio): %d\n", contador);
9 // Reasignación 2: El nuevo valor se basa en el valor actual (5 + 1).
10
11 contador = contador + 1; // Ahora 'contador' vale 6
12 printf("Contador (Segundo cambio): %d\n", contador);
13
14 return 0;
15}

Salida Esperada:

Contador (Inicio): 1

Contador (Primer cambio): 5

Contador (Segundo cambio): 6
