Ejercicios de Programación: Variables en C

Ejercicio 1: Declaración en Dos Pasos (Separado)

Instrucción: Declara una variable int llamada horas_trabajadas. En una línea separada, inicialízala con el valor 40. Finalmente, imprime el valor.

Solución en C:

C

#include <stdio.h>

int main(void) {

int horas_trabajadas; // Declaración

horas_trabajadas = 40; // Inicialización

printf("Horas trabajadas: %d\n", horas_trabajadas);

return 0;

}

Salida Esperada:

Horas trabajadas: 40

Ejercicio 2: Inicialización Directa (Recomendada)

Instrucción: Declara e inicializa directamente (un solo paso) tres variables: distancia (float con valor 150.5f), calificacion (char con valor 'A') y precio_unitario (double con valor 19.99). Imprime los tres valores.

Solución en C:

C

#include <stdio.h>

int main(void) {

float distancia = 150.5f;

char calificacion = 'A';

double precio_unitario = 19.99;

printf("Distancia: %.1f km\n", distancia);

printf("Calificación: %c\n", calificacion);

printf("Precio: %.2lf\n", precio_unitario);

return 0;

}

Salida Esperada:

Distancia: 150.5 km

Calificación: A

Precio: 19.99

Ejercicio 3: El Misterio del Valor Basura (Advertencia)

Instrucción: Declara una variable int llamada valor_sin_init y NO la inicialices. Intenta imprimir su valor. Añade un comentario en la salida sobre por qué el resultado es impredecible.

Solución en C:

C

#include <stdio.h>

int main(void) {

int valor_sin_init; // Declarada, pero no inicializada

printf("El valor de la variable sin inicializar es: %d\n", valor_sin_init);

printf("--- ADVERTENCIA: Este valor es basura e impredecible ---\n");

return 0;

}

Salida Esperada (El número cambiará, pero la estructura es constante):

El valor de la variable sin inicializar es: [NUMERO ALEATORIO GRANDE O PEQUEÑO]

--- ADVERTENCIA: Este valor es basura e impredecible ---

Ejercicio 4: Reasignación de un Contador

Instrucción: Inicializa un int llamado contador a 0. En la siguiente línea, reasígnalo a 10. Finalmente, usa la reasignación para incrementar su valor en 1 (usando contador = contador + 1;). Imprime el valor final.

Solución en C:

C

#include <stdio.h>

int main(void) {

int contador = 0; // Inicialización a 0

contador = 10; // Reasignación a 10

contador = contador + 1; // Reasignación: 10 + 1 = 11

printf("Valor final del contador: %d\n", contador);

return 0;

}

Salida Esperada:

Valor final del contador: 11

Ejercicio 5: Uso de Variables en Operaciones Aritméticas

Instrucción: Declara e inicializa un float llamado radio a 5.0f. Declara otro float llamado area. Usa el valor de radio para calcular el área del círculo ($\text{Área} = 3.14159 \times \text{radio} \times \text{radio}$) y asigna el resultado a la variable area.

Solución en C:

C

#include <stdio.h>

int main(void) {

float radio = 5.0f;

float area; // Declaración de la variable donde se guardará el resultado

// Uso del valor de 'radio' en la fórmula

area = 3.14159f * radio * radio;

printf("El área del círculo es: %.2f\n", area);

return 0;

}

Salida Esperada:

El área del círculo es: 78.54

Ejercicio 6: Reasignación para Cambio de Estado

Instrucción: Declara una variable char llamada estado e inicialízala con 'P' (Pendiente). Usa printf() para mostrar el estado inicial. Luego, reasigna estado a 'C' (Completado) y vuelve a imprimir el nuevo estado.

Solución en C:

C

#include <stdio.h>

int main(void) {

char estado = 'P';

printf("Estado inicial: %c (Pendiente)\n", estado);

estado = 'C'; // Reasignación

printf("Nuevo estado: %c (Completado)\n", estado);

return 0;

}

Salida Esperada:

Estado inicial: P (Pendiente)

Nuevo estado: C (Completado)

Ejercicio 7: Reasignación de Tipo Entero desde Float

Instrucción: Inicializa un double llamado valor_bruto a 15.75. Declara un int llamado valor_entero. Reasigna valor_entero a una conversión del valor_bruto (sin usar cast, para demostrar la reasignación con truncamiento). Imprime el valor final de valor_entero.

Solución en C:

C

#include <stdio.h>

int main(void) {

double valor_bruto = 15.75;

int valor_entero;

// Reasignación: la parte .75 se pierde (truncamiento)

valor_entero = valor_bruto;

printf("El valor entero final es: %d\n", valor_entero);

return 0;

}

Salida Esperada:

El valor entero final es: 15

Ejercicio 8: Inicialización Múltiple Segura

Instrucción: Inicializa tres variables int en una sola línea (x, y, z), todas con el valor inicial de 0. Luego, reasigna x a 5 y y a 10. Imprime la suma de las tres variables.

Solución en C:

C

#include <stdio.h>

int main(void) {

int x = 0, y = 0, z = 0; // Inicialización múltiple

x = 5; // Reasignación

y = 10; // Reasignación

// Uso de variables

int suma = x + y + z;

printf("La suma final (5 + 10 + 0) es: %d\n", suma);

return 0;

}

Salida Esperada:

La suma final (5 + 10 + 0) es: 15
