Ejercicios: Límites, Rangos y Desbordamiento

Ejercicio 1: Mostrando el Límite Máximo de int

Instrucción: Incluye el header <limits.h> e imprime el valor exacto de la constante INT_MAX.

Solución en C:

C

#include <stdio.h>

#include <limits.h>

int main(void) {

printf("El valor máximo de un int es: %d\n", INT_MAX);

return 0;

}

Output Esperado (Típico 32-bit):

El valor máximo de un int es: 2147483647

Ejercicio 2: Desbordamiento (Overflow y Wrap Around)

Instrucción: Inicializa una variable int con el valor INT_MAX. Súmale 1 y luego imprime el resultado para demostrar el efecto de wrap around al límite negativo.

Solución en C:

C

#include <stdio.h>

#include <limits.h>

int main(void) {

int contador = INT_MAX;

printf("Valor inicial (INT_MAX): %d\n", contador);

contador = contador + 1; // Causando Overflow

printf("Valor después de +1: %d\n", contador);

return 0;

}

Output Esperado (Típico 32-bit):

Valor inicial (INT_MAX): 2147483647

Valor después de +1: -2147483648

Ejercicio 4: Uso de unsigned int (Sin Signo)

Instrucción: Declara una variable como unsigned int llamada capacidad. Inicialízala con un valor grande (ej. 4,000,000,000). Imprime este valor usando el especificador %u.

Solución en C:

C

return 0;

}

Output Esperado:

Capacidad máxima de almacenamiento: 4000000000

Ejercicio 5: unsigned y el Valor Negativo Ilegal

Instrucción: Declara una variable unsigned int. Intenta asignarle un valor negativo (-1) y observa (imprime) el valor que el compilador le asigna debido al wrap around.

Solución en C:

C

#include <stdio.h>

#include <limits.h>

int main(void) {

// Al asignar -1 a un unsigned int, se produce un overflow y salta a UINT_MAX.

unsigned int error_valor = -1;

printf("Valor asignado a unsigned int de -1: %u\n", error_valor);

printf("--- Esto es UINT_MAX en el sistema. ---\n");

return 0;

}

Output Esperado (Típico 32-bit):

Valor asignado a unsigned int de -1: 4294967295

--- Esto es UINT_MAX en el sistema. ---

Ejercicio 7: Desbordamiento de unsigned int (Cíclico)

Instrucción: Inicializa una variable unsigned int con UINT_MAX. Súmale 1 e imprime el resultado. (En unsigned, el wrap around es de UINT_MAX + 1 a 0).

Solución en C:

C

#include <stdio.h>

#include <limits.h>

int main(void) {

unsigned int ciclo_up = UINT_MAX;

printf("UINT_MAX: %u\n", ciclo_up);

ciclo_up = ciclo_up + 1; // Causa wrap around a 0

printf("UINT_MAX + 1 = %u\n", ciclo_up);

return 0;

}

Output Esperado (Típico 32-bit):

UINT_MAX: 4294967295

UINT_MAX + 1 = 0

Ejercicio 11: Mezcla de signed y unsigned (Peligro)

Instrucción: Declara un signed int (-10) y un unsigned int (1). Réstalos y asigna el resultado a un signed int. Explica por qué el unsigned fuerza la operación a comportarse como sin signo.

Solución en C:

C

#include <stdio.h>

int main(void) {

int A = -10;

unsigned int B = 1;

// El 'int' A se convierte a 'unsigned int' durante la resta,

// lo que resulta en un número positivo muy grande.

int resultado = A - B;

printf("A: %d\n", A);

printf("B: %u\n", B);

printf("Resultado (A - B): %d\n", resultado);

return 0;

}

Output Esperado (Resultado del cálculo a nivel de bits como unsigned):

A: -10

B: 1

Resultado (A - B): -11 // El resultado es -11, pero internamente la operación fue unsigned: 4294967286

Ejercicio 12: Usando signed char

Instrucción: Define una variable como signed char e inicialízala con un valor cerca del límite positivo (ej. 120). Súmale 10 y comprueba el wrap around al límite negativo de char.

Solución en C:

C

#include <stdio.h>

#include <limits.h>

int main(void) {

// char MAX es 127. 120 + 10 = 130.

signed char valor_char = 120;

valor_char = valor_char + 10;

printf("Límite de char: %d\n", CHAR_MAX);

printf("120 + 10 (char overflow): %d\n", valor_char);

return 0;

}

Output Esperado (130 - 256 = -126):

Límite de char: 127

120 + 10 (char overflow): -126

Ejercicio 15: Desbordamiento de Punto Flotante (float)

Instrucción: Inicializa una variable float con FLT_MAX (usando <float.h>). Multiplícala por 2.0f y observa el resultado. (El resultado del overflow de flotantes a menudo es inf (infinito)).

Solución en C:

C

#include <stdio.h>

#include <float.h>

int main(void) {

float max_f = FLT_MAX;

printf("Valor inicial (FLT_MAX): %e\n", max_f);

// Multiplicar por 2.0f causará un desbordamiento.

float resultado = max_f * 2.0f;

printf("Resultado del Overflow: %f\n", resultado);

return 0;

}

Output Esperado (Típico IEEE 754):

Valor inicial (FLT_MAX): 3.402823e+38

Resultado del Overflow: inf
