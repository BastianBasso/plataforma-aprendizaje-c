Ejercicio 6.1: Validación de Nombres (Reglas de C)

Objetivo: Identificar nombres de variables válidos e inválidos según las reglas estrictas del compilador C (Reglas de Nomenclatura).

Instrucción: Clasifica los siguientes nombres como Válido (V) o Inválido (I). Si es inválido, explica la regla que rompe.

Nombre Propuesto Clasificación Regla Rota (Si es Inválido)
limite-maximo
int
_contador
2da_oportunidad
EdadTotal

Solución:

Nombre Propuesto Clasificación Regla Rota (Si es Inválido)
limite-maximo I Contiene el caracter especial - (guion medio), que es el operador de resta.
int I Es una palabra reservada del lenguaje C.
_contador V Comienza con _ y no rompe reglas sintácticas (aunque su uso se desaconseja para variables de usuario).
2da_oportunidad I No puede comenzar con un dígito (2).
EdadTotal V Es un nombre válido (letras), aunque no sigue la convención Snake Case de C.

Ejercicio 6.2: Refactorización (Claridad y Estilo)

Objetivo: Aplicar la Regla de Oro (Claridad) y el Snake Case (Estilo) para mejorar la legibilidad.

Instrucción: Refactoriza el siguiente fragmento de código (escrito con nombres pobres) utilizando nombres descriptivos, la convención Snake Case para variables y Mayúsculas con guiones bajos para constantes.

Código Original:

C

#define IVA 0.19

int c = 100;

float Pfinal = c * (1 + IVA);

Solución Refactorizada en C:

C

#include <stdio.h>

// 1. Constante simbólica: MAYÚSCULAS y nombre descriptivo

#define TASA_IVA 0.19

int main(void) {

// 2. Variable: Snake Case y descriptiva (monto_bruto)

int monto_base = 100;

// 3. Variable: Snake Case y descriptiva (precio_final)

float precio_final = monto_base * (1 + TASA_IVA);

printf("Precio Final: %.2f\n", precio_final);

return 0;

}

Ejercicio 6.3: Declaración Cerca del Uso (C99+)

Objetivo: Entender la ventaja de la declaración tardía (C99+) para mejorar el scope y la legibilidad.

Instrucción: Reescribe el siguiente fragmento de código (escrito en el estilo antiguo C89) para que siga la recomendación moderna de declarar las variables lo más cerca posible de su primer uso.

Código Original (Estilo C89):

C

int i;

int total_acumulado = 0;

// [100 líneas de código que no usan estas variables]

for (i = 0; i < 50; i++) {

total_acumulado += i;

}

Solución Refactorizada (Estilo C99/Moderno):

C

#include <stdio.h>

void calcular_totales(void) {

// Declaración tardía: total_acumulado se declara justo antes de su uso.

int total_acumulado = 0;

// [100 líneas de código que no usan estas variables]

// ...

// Declaración tardía: la variable de control 'i' se declara DENTRO del bucle 'for'.

// Esto limita el alcance (scope) de 'i' solo al bucle.

for (int i = 0; i < 50; i++) {

total_acumulado += i;

}

printf("Total Acumulado: %d\n", total_acumulado);

}

int main(void) {

calcular_totales();

return 0;

}
