Proyecto del Módulo 2: Calculadora de Inversión Financiera

Este proyecto desafiante está diseñado para que apliques y consolides todos los conceptos aprendidos en el Módulo 2: Tipos de Datos, Variables, Constantes, Límites y Conversión de Tipos (Casting).

El objetivo es construir una calculadora que determine el valor futuro de una inversión, manejando las entradas del usuario y asegurando que los cálculos sean precisos y que el manejo de datos sea seguro.

Objetivo del Proyecto: Cálculo de Valor Futuro (Interés Compuesto)

Implementar un programa en C que calcule el valor futuro de una inversión utilizando la fórmula de interés compuesto. El programa debe gestionar los tipos de datos cuidadosamente para evitar desbordamientos y asegurar la precisión decimal.

Valor Futuro = Capital Inicial × (1 + Tasa de Interés)^(Años)

Requisitos de Implementación

El programa debe cumplir con los siguientes puntos, aplicando las buenas prácticas y conceptos aprendidos:

1. Gestión de Constantes y Nomenclatura (Secciones 4 y 6)

  • Constante de Tasa Fija: Define una constante para la tasa de interés base (ej. $0.05$ para $5\%$). Utiliza el calificador const y la convención de nomenclatura MAYÚSCULAS_CON_GUION_BAJO (ej., TASA_INTERES_BASE).

  • Constante Simbólica: Define el número máximo de años para la inversión (ej., $50$) usando #define (ej., MAX_ANOS).

2. Manejo de Variables y Tipos (Secciones 1, 2 y 6)

  • Entradas del Usuario: Declara variables para almacenar:

    • Capital Inicial: Utiliza el tipo double para asegurar alta precisión y un gran rango de capital.

    • Años de Inversión: Utiliza un tipo int o unsigned int (argumenta por qué eliges uno sobre el otro en los comentarios).

  • Salida del Resultado: La variable valor_futuro debe ser de tipo double.

  • Buenas Prácticas:

    • Utiliza Snake Case (capital_inicial) para todas las variables.

    • Asegúrate de que las variables se declaren lo más cerca posible de su uso (estilo C99+).

3. Validación y Desbordamiento (Sección 5)

  • Protección contra Overflow: Incluye el header <limits.h>. Antes de calcular el valor futuro, crea una condición que compruebe si el número de años introducido por el usuario excede la constante MAX_ANOS o si es negativo. Si lo hace, imprime un mensaje de error y finaliza el programa.

  • Uso de long double (Desafío Extra): Para el cálculo del Valor Futuro, realiza el cálculo intermedio utilizando long double (el tipo con mayor rango) para demostrar que puedes manejar la máxima precisión posible, y luego asigna el resultado final a la variable valor_futuro de tipo double.

4. Conversión y Precisión (Casting - Sección Extra 4)

  • Casting para Impresión: Al imprimir el resultado final (valor_futuro), utiliza el especificador %lf o %le para mostrar la precisión.

  • Desafío de la Tasa: Si el usuario ingresa la tasa como un porcentaje entero (ej. $5$), usa Casting Explícito para convertir ese entero a su valor decimal correcto (ej. $\text{tasa}/100.0$) antes de usarlo en la fórmula.

Instrucciones de Entrega

  1. El código debe compilar sin advertencias ni errores con el estándar C99 o superior.

  2. Cada sección de código que implemente un concepto del módulo (constantes, casting, límites) debe ir acompañada de un comentario explicativo que justifique la elección del tipo o la práctica utilizada.

  3. Incluye una prueba donde el programa muestre un resultado válido y otra donde muestre el mensaje de error por exceder MAX_ANOS.

Solución Propuesta: Calculadora de Valor Futuro

Este código utiliza las librerías stdio.h para entrada/salida, math.h para la función de potencia, y limits.h para la validación de límites.

Código Fuente en C

C

1#include <stdio.h>
2#include <math.h> // Necesario para la función pow()
3#include <limits.h> // Necesario para la validación de límites
4
5// 1. Constante Simbólica (Uso de #define para un límite fijo)
6#define MAX_ANOS 50
7
8// 2. Constante Tipada (Uso de 'const' con Snake Case Mayúsculas)
9const double TASA_INTERES_BASE = 0.05; // 5%
10
11int main(void) {
12 // Variables declaradas cerca del uso (Estilo C99+) y usando Snake Case
13
14 printf("==========================================\n");
15 printf(" Calculadora de Inversión (Módulo 2) \n");
16 printf("==========================================\n");
17 printf("Tasa de interés base: %.2f%%\n", TASA_INTERES_BASE * 100);
18
19 // Declaración de variables para entradas
20 double capital_inicial; // Tipo double para gran precisión en dinero
21 int anos_inversion; // Tipo int para contar años
22
23 // 3. Lectura del Capital Inicial
24 printf("Ingrese capital inicial (ej. 10000.00): ");
25 if (scanf("%lf", &capital_inicial) != 1 || capital_inicial <= 0) {
26 fprintf(stderr, "Error: Capital inicial inválido.\n");
27 return 1;
28 }
29
30 // 4. Lectura de Años de Inversión
31 printf("Ingrese años de inversión (máx. %d): ", MAX_ANOS);
32 if (scanf("%d", &anos_inversion) != 1) {
33 fprintf(stderr, "Error: Entrada de años inválida.\n");
34 return 1;
35 }
36
37 // 5. Protección contra Overflow y Validación
38 if (anos_inversion < 0) {
39 fprintf(stderr, "\nERROR: Los años de inversión no pueden ser negativos (violación de rango).\n");
40 return 1;
41 }
42 if (anos_inversion > MAX_ANOS) {
43 // Validación contra la constante simbólica
44 fprintf(stderr, "\nERROR: El número de años excede el límite (%d años).\n", MAX_ANOS);
45 return 1;
46 }
47
48 // 6. Cálculo del Valor Futuro con long double para máxima precisión intermedia
49 // Uso del tipo long double, el tipo flotante con mayor rango y precisión en C.
50 long double factor_interes = 1.0 + TASA_INTERES_BASE;
51 long double potencia = pow(factor_interes, (long double)anos_inversion);
52
53 // 7. Casting Explícito (Conversión de tipo)
54 // Se fuerza el cálculo a double para la variable final.
55 double valor_futuro = (double)capital_inicial * potencia;
56
57 printf("\nCalculando...\n");
58 printf("El factor de potencia (1 + 0.05)^%d es: %.6Lf\n", anos_inversion, potencia);
59
60 // 8. Impresión del Resultado Final
61 // Usando %lf para imprimir el resultado de tipo double
62 printf("El valor futuro de la inversión es: %.2lf\n", valor_futuro);
63
64 return 0;
65}
