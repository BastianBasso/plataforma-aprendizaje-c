2. Operadores Relacionales y Lógicos (Bases para la Decisión)

Concepto de Expresión Booleana (Lógica)

Una Expresión Booleana (o expresión lógica) es cualquier sentencia que, al ser evaluada, solo puede tener uno de dos resultados posibles: Verdadero o Falso. Estas expresiones son la base de la toma de decisiones y el flujo de control en la programación.

El Modelo Booleano en C

A diferencia de otros lenguajes que tienen un tipo de dato explícito llamado boolean o bool (aunque C99 introdujo el header <stdbool.h>), el lenguaje C representa los valores lógicos utilizando el tipo de dato entero (int):

Valor Lógico Representación en C (Entero)
Falso (False) Cero (0)
Verdadero (True) Cualquier valor distinto de cero (Generalmente se utiliza el Uno (1))

Ejemplo:

Si realizas una comparación simple como 5 > 3, el compilador C no devuelve la palabra "Verdadero", sino el valor entero $\mathbf{1}$.

Si realizas una comparación como 10 == 2, el compilador C devuelve el valor entero $\mathbf{0}$.

La Importancia del Cero (0)

En C, el concepto de "Falsedad" está ligado de manera fundamental al valor $\mathbf{0}$.

  • Cuando una expresión lógica devuelve un resultado, lo hace como $\mathbf{0}$ o $\mathbf{1}$.

  • Cuando una estructura de control (como un if) evalúa una condición, trata el valor $\mathbf{0}$ como Falso y cualquier otro número (incluyendo números negativos o enteros mayores que 1) como Verdadero.

Código de Ejemplo:

C

#include <stdio.h>

int main(void) {

int resultado_comparacion;

// El resultado es Verdadero, C lo representa con 1

resultado_comparacion = (10 > 5);

printf("Resultado de (10 > 5): %d\n", resultado_comparacion);

// El resultado es Falso, C lo representa con 0

resultado_comparacion = (10 == 5);

printf("Resultado de (10 == 5): %d\n", resultado_comparacion);

return 0;

}

Operadores Relacionales (Comparación)

Los operadores relacionales (o de comparación) se utilizan para establecer una relación entre dos operandos. Al igual que con las expresiones booleanas, el resultado de cualquier comparación en C siempre será Verdadero (representado como $\mathbf{1}$) o Falso (representado como $\mathbf{0}$).

Tabla de Operadores de Comparación

Operador Lectura Significado Ejemplo Resultado (Valor Lógico)
== Igual a Comprueba si ambos operandos son exactamente iguales. 5 == 5 1 (Verdadero)
!= Distinto de Comprueba si ambos operandos no son iguales. 10 != 5 1 (Verdadero)
> Mayor que Comprueba si el operando izquierdo es mayor que el derecho. 12 > 7 1 (Verdadero)
< Menor que Comprueba si el operando izquierdo es menor que el derecho. 3 < 8 1 (Verdadero)
>= Mayor o igual que Comprueba si es mayor o igual. 4 >= 4 1 (Verdadero)
<= Menor o igual que Comprueba si es menor o igual. 9 <= 5 0 (Falso)

Diferencia Fundamental: Asignación vs. Comparación

Este es el punto de error más común para los principiantes en C. Es crucial entender que los signos de igualdad simple y doble tienen funciones completamente diferentes:

1. Asignación (=)

  • Propósito: Asignar un valor.

  • Función: Mueve el valor de la derecha hacia la variable de la izquierda.

  • Resultado: No produce un resultado booleano, sino que modifica el valor de una variable.

$$\text{Ejemplo: } \mathbf{\text{edad} \space = \space 30}\text{;} \quad \text{("Edad ahora vale 30")}$$

2. Comparación (==)

  • Propósito: Evaluar la igualdad.

  • Función: Compara si el valor de la izquierda es igual al valor de la derecha.

  • Resultado: Produce un valor booleano (1 o 0).

$$\text{Ejemplo: } \mathbf{\text{edad} \space == \space 30}\text{?} \quad \text{("¿Edad es igual a 30?")}$$

Advertencia: Usar accidentalmente = donde se esperaba == (por ejemplo, en un bloque if) es un error común que puede llevar a errores de lógica graves difíciles de depurar, ya que la asignación (=) siempre produce un valor (que en la mayoría de los casos no será $0$, evaluándose como Verdadero).

Operadores Lógicos (Compuertas) 🔗

Mientras que los operadores relacionales (>, ==, etc.) comparan dos valores, los operadores lógicos se utilizan para combinar o modificar los resultados de estas expresiones booleanas (los $\mathbf{0}$s y $\mathbf{1}$s).

Permiten crear condiciones complejas, como "si A es verdadero Y B es verdadero" o "si A es verdadero O B es verdadero".

Operador Nombre Significado Ejemplo (Resultado)
&& AND Lógico Devuelve Verdadero (1) solo si ambas expresiones son verdaderas. (5 > 1) && (10 == 10) (1 y 1) $\rightarrow$ 1
**` `** OR Lógico
! NOT Lógico (Negación) Invierte el valor lógico. Convierte Verdadero (1) en Falso (0) y viceversa. !(5 < 1) (No Falso) $\rightarrow$ 1

Uso para Combinar Condiciones

Estos operadores son la base de la toma de decisiones complejas. Permiten encadenar múltiples verificaciones en una sola sentencia.

Ejemplo Práctico en C:

C

#include <stdio.h>

int main(void) {

int edad = 25;

int tiene_licencia = 1; // 1 = Verdadero

// AND: ¿Es mayor de edad (>=18) Y tiene licencia?

int puede_conducir = (edad >= 18) && (tiene_licencia == 1);

// (1) && (1) = 1 (Verdadero)

printf("¿Puede conducir?: %d\n", puede_conducir);

// OR: ¿Tiene un descuento? (Si es menor de 12 O mayor de 65)

int tiene_descuento = (edad < 12) || (edad > 65);

// (0) || (0) = 0 (Falso)

printf("¿Tiene descuento?: %d\n", tiene_descuento);

// NOT: ¿No es un adolescente?

int no_adolescente = !( (edad > 12) && (edad < 20) );

// !( 1 && 0 ) = !(0) = 1 (Verdadero)

printf("¿No es adolescente?: %d\n", no_adolescente);

return 0;

}

Tablas de Verdad Simples

Las Tablas de Verdad son herramientas fundamentales en la lógica que demuestran todas las posibles combinaciones de resultados para un operador lógico dado. Dado que en C solo hay dos estados (Verdadero = $\mathbf{1}$, Falso = $\mathbf{0}$), estas tablas son sencillas y definitivas.

Usaremos $\mathbf{A}$ y $\mathbf{B}$ para representar dos condiciones booleanas de entrada.

1. Tablas para && (AND Lógico)

El operador AND (&&) requiere que todas las condiciones de entrada sean Verdaderas para que la expresión completa sea Verdadera.

A B A && B Explicación
$\mathbf{0}$ (Falso) $\mathbf{0}$ (Falso) $\mathbf{0}$ (Falso) Falso y Falso $\rightarrow$ Falso
$\mathbf{0}$ (Falso) $\mathbf{1}$ (Verdadero) $\mathbf{0}$ (Falso) Falso y Verdadero $\rightarrow$ Falso
$\mathbf{1}$ (Verdadero) $\mathbf{0}$ (Falso) $\mathbf{0}$ (Falso) Verdadero y Falso $\rightarrow$ Falso
$\mathbf{1}$ (Verdadero) $\mathbf{1}$ (Verdadero) $\mathbf{1}$ (Verdadero) Verdadero y Verdadero $\rightarrow$ Verdadero

Recordatorio: Si estás verificando que un número esté en un rango (ej: $5 < x < 10$), necesitas el &&: (x > 5) && (x < 10).

2. Tablas para || (OR Lógico)

El operador OR (||) requiere que al menos una de las condiciones de entrada sea Verdadera para que la expresión completa sea Verdadera.

| A | B | A $\mathbf{||}$ B | Explicación |

| :---: | :---: | :---: | :--- |

| $\mathbf{0}$ (Falso) | $\mathbf{0}$ (Falso) | $\mathbf{0}$ (Falso) | Falso o Falso $\rightarrow$ Falso (Único caso) |

| $\mathbf{0}$ (Falso) | $\mathbf{1}$ (Verdadero) | $\mathbf{1}$ (Verdadero) | Falso o Verdadero $\rightarrow$ Verdadero |

| $\mathbf{1}$ (Verdadero) | $\mathbf{0}$ (Falso) | $\mathbf{1}$ (Verdadero) | Verdadero o Falso $\rightarrow$ Verdadero |

| $\mathbf{1}$ (Verdadero) | $\mathbf{1}$ (Verdadero) | $\mathbf{1}$ (Verdadero) | Verdadero o Verdadero $\rightarrow$ Verdadero |

3. Tabla para ! (NOT Lógico)

El operador NOT (!) solo opera sobre una condición y simplemente invierte su valor lógico.

A ! A Explicación
$\mathbf{0}$ (Falso) $\mathbf{1}$ (Verdadero) La negación de Falso es Verdadero
$\mathbf{1}$ (Verdadero) $\mathbf{0}$ (Falso) La negación de Verdadero es Falso
