15 Ejercicios: Prioridad de Operadores y Expresiones

Parte 1: Precedencia (Multiplicación/División antes que Suma/Resta)

Instrucción: Predice el resultado de las siguientes expresiones basándote en la jerarquía de operadores.

# Descripción Código en C Output Esperado
1 Multiplicación antes que Suma int r = 5 + 2 * 3; printf("%d", r); 11
2 División antes que Resta int r = 10 - 6 / 2; printf("%d", r); 7
3 Módulo antes que Suma int r = 20 + 7 % 3; printf("%d", r); 21
4 Múltiples Operadores (Alta Prioridad) int r = 8 * 2 + 10 / 5; printf("%d", r); 18

Parte 2: Paréntesis (Forzando el Orden)

Instrucción: Predice el resultado de las expresiones donde los paréntesis anulan la precedencia natural.

# Descripción Código en C Output Esperado
5 Paréntesis fuerzan Suma int r = (5 + 2) * 3; printf("%d", r); 21
6 Paréntesis fuerzan Resta int r = (10 - 6) / 2; printf("%d", r); 2
7 Paréntesis en el Divisor int r = 100 / (10 + 10); printf("%d", r); 5
8 Paréntesis Anidados int r = (5 * (4 + 1)) / 5; printf("%d", r); 5

Parte 3: Asociatividad (Desempate)

Instrucción: Predice el resultado basándote en la asociatividad (L-a-R para aritméticos, R-a-L para asignación).

# Descripción Código en C Output Esperado
9 L-a-R (División y Multiplicación) int r = 100 / 10 * 2; printf("%d", r); 20
10 L-a-R (Suma y Resta) int r = 20 - 5 + 3; printf("%d", r); 18
11 L-a-R (Cadena *, /, %) int r = 10 * 4 / 5 % 3; printf("%d", r); 2
12 R-a-L (Asignación en Cadena) int a, b, c; a = b = c = 10; printf("%d", a); 10

Parte 4: Expresiones Complejas y Claridad

Instrucción: Calcula el resultado de estas expresiones combinadas.

# Descripción Código en C Output Esperado
13 Expresión Mixta Compleja int r = 10 + 5 * 2 - 8 / 4; printf("%d", r); 18
14 Mixta con Paréntesis y Módulo int r = (10 + 5) * 2 - (9 % 4); printf("%d", r); 29
15 Paréntesis para Claridad int a = 12, b = 6, c = 2; int r = (a / b) + (a / c); printf("%d", r); 8

Código Completo de las Respuestas

C

#include <stdio.h>

int main(void) {

int r, a, b, c;

printf("--- Parte 1: Precedencia ---\n");

// 1. 5 + (2 * 3) = 11

r = 5 + 2 * 3;

printf("1. Resultado: %d\n", r);

// 2. 10 - (6 / 2) = 7

r = 10 - 6 / 2;

printf("2. Resultado: %d\n", r);

// 3. 20 + (7 % 3) = 20 + 1 = 21

r = 20 + 7 % 3;

printf("3. Resultado: %d\n", r);

// 4. (8 * 2) + (10 / 5) = 16 + 2 = 18

r = 8 * 2 + 10 / 5;

printf("4. Resultado: %d\n", r);

printf("\n--- Parte 2: Paréntesis ---\n");

// 5. (5 + 2) * 3 = 7 * 3 = 21

r = (5 + 2) * 3;

printf("5. Resultado: %d\n", r);

// 6. (10 - 6) / 2 = 4 / 2 = 2

r = (10 - 6) / 2;

printf("6. Resultado: %d\n", r);

// 7. 100 / (10 + 10) = 100 / 20 = 5

r = 100 / (10 + 10);

printf("7. Resultado: %d\n", r);

// 8. (5 * 5) / 5 = 25 / 5 = 5

r = (5 * (4 + 1)) / 5;

printf("8. Resultado: %d\n", r);

printf("\n--- Parte 3: Asociatividad ---\n");

// 9. (100 / 10) * 2 = 10 * 2 = 20

r = 100 / 10 * 2;

printf("9. Resultado: %d\n", r);

// 10. (20 - 5) + 3 = 15 + 3 = 18

r = 20 - 5 + 3;

printf("10. Resultado: %d\n", r);

// 11. ((10 * 4) / 5) % 3 = (40 / 5) % 3 = 8 % 3 = 2

r = 10 * 4 / 5 % 3;

printf("11. Resultado: %d\n", r);

// 12. a = (b = (c = 10))

a = b = c = 10;

printf("12. Resultado (valor de a): %d\n", a);

printf("\n--- Parte 4: Complejas ---\n");

// 13. 10 + (5 * 2) - (8 / 4) = 10 + 10 - 2 = 18

r = 10 + 5 * 2 - 8 / 4;

printf("13. Resultado: %d\n", r);

// 14. (15 * 2) - (9 % 4) = 30 - 1 = 29

r = (10 + 5) * 2 - (9 % 4);

printf("14. Resultado: %d\n", r);

// 15. (12 / 6) + (12 / 2) = 2 + 6 = 8

a = 12; b = 6; c = 2;

r = (a / b) + (a / c);

printf("15. Resultado: %d\n", r);

return 0;

}
