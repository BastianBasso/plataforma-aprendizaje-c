4. Entrada Estándar de Datos (Input): Captura de Valores

La Función scanf() (Input Estándar)

La función scanf() (Scan Formatted) es la herramienta fundamental en C para manejar la entrada estándar de datos (Standard Input), que típicamente es lo que el usuario escribe en el teclado y ve en la consola. Su propósito es capturar y leer información para que el programa pueda procesarla.

Propósito y Sintaxis

scanf() toma los datos ingresados por el usuario y los guarda en una variable dentro de la memoria del programa. Requiere el header <stdio.h>, al igual que printf().

La sintaxis básica es:

$$\text{scanf}(\text{"especificador de formato", } \text{dirección de la variable})\text{;}$$

Ejemplo:

Si queremos leer un número entero (int) y almacenarlo en la variable edad:

C

int edad;

scanf("%d", &edad); // Aquí el programa se detiene y espera la entrada.

Diferencias Clave con printf()

Aunque scanf() y printf() comparten el uso de especificadores de formato (como %d), sus roles son opuestos:

  • printf(): Muestra datos desde el programa hacia la consola (Salida).

  • scanf(): Captura datos desde la consola hacia el programa (Entrada).

Es una buena práctica usar siempre printf() inmediatamente antes de scanf() para mostrar un mensaje (prompt) al usuario, indicándole qué tipo de dato debe ingresar (por ejemplo: "Ingrese su edad: "). Esto mejora la experiencia del usuario.

Especificadores de Formato para scanf()

Los especificadores de formato son cadenas de texto que comienzan con el signo de porcentaje (%) y le indican a la función scanf() qué tipo de dato debe esperar del usuario y cómo debe interpretarlo y almacenarlo en la memoria.

Aunque se parecen a los usados en printf(), algunos cambian para la entrada:

Especificador Tipo de Dato en C Descripción
%d int Lee un valor entero decimal.
%f float Lee un valor de punto flotante de precisión simple.
%lf double Lee un valor de punto flotante de doble precisión. (¡Nota importante!)
%c char Lee un único carácter.
%s Cadena de caracteres Lee una secuencia de caracteres (se verá más adelante).

Diferencia Clave: %f vs. %lf

En la salida (printf), se usa %f tanto para float como para double. Sin embargo, en la entrada (scanf):

  • Usa %f solo para leer variables de tipo float.

  • Usa %lf para leer variables de tipo double.

Ejemplo de Uso:

C

#include <stdio.h>

int main(void) {

int edad;

float peso;

double altura;

printf("Ingrese su edad (entero): ");

scanf("%d", &edad); // Usamos %d

printf("Ingrese su peso (float): ");

scanf("%f", &peso); // Usamos %f

printf("Ingrese su altura (double): ");

scanf("%lf", &altura); // ¡Usamos %lf para double!

return 0;

}

El Operador de Dirección (&)

El Operador de Dirección (&), también conocido como el operador de referencia o "dirección de", es un concepto absolutamente crucial cuando se utiliza la función scanf(). Su uso es obligatorio para la mayoría de los tipos de datos básicos y representa una introducción práctica al concepto de punteros en C.

¿Por qué Necesitamos & en scanf()?

Cuando se llama a una función en C, normalmente se pasa una copia del valor de la variable (lo que se llama paso por valor). Sin embargo, scanf() necesita hacer lo contrario: necesita modificar la variable original.

  1. Ubicación, no Valor: scanf() no necesita el valor actual de la variable edad (aún no tiene un valor o tiene basura). En cambio, necesita saber la dirección exacta en la memoria donde está almacenada la variable edad.

  2. El Rol de &: El operador & se coloca inmediatamente antes del nombre de la variable y le dice a scanf(): "Aquí está la dirección de memoria donde debes escribir el valor que el usuario va a ingresar."

Sintaxis Correcta (Obligatorio) Explicación
scanf("%d", **&**edad); Pasa la dirección de edad. scanf() usa esa dirección para guardar el nuevo número.
Sintaxis Incorrecta (Error) Explicación
scanf("%d", edad); Pasa el valor de edad (una copia). scanf() no puede saber dónde guardar el resultado.

Analagía: Imagina que quieres enviar una carta a un amigo (scanf). No le envías el contenido actual de su buzón (el valor de la variable), sino que necesitas saber la dirección de su casa (&variable) para poder dejar el nuevo contenido allí.

En términos técnicos, al usar &, estamos realizando un paso por referencia, permitiendo que la función scanf() cambie directamente el contenido de la variable definida en la función main (o la función llamadora).

Captura de Cadenas (%s) (Concepto Inicial)

Para capturar texto, como un nombre o una palabra, C utiliza el concepto de cadenas de caracteres. Técnicamente, una cadena es un arreglo (array) de caracteres. Aunque los arrays se cubrirán en un módulo posterior, es necesario declarar una variable de cadena para usar %s en scanf().

1. Declaración de la Cadena

Para decirle a C que reserve espacio para una palabra o frase, usamos la sintaxis:

$$\text{char } \text{nombre\_variable}[\text{tamaño\_máximo}]\text{;}$$

El tamaño máximo indica cuántos caracteres puede almacenar la cadena (debe ser lo suficientemente grande para el texto más el carácter nulo \0 que marca el final de toda cadena en C).

Ejemplo de Declaración:

C

char nombre[50]; // Reserva espacio para hasta 49 caracteres más el \0

2. Uso de %s en scanf()

El especificador de formato %s se usa para leer cadenas.

Tipo de Dato Especificador Operador &
Cadena (Array de char) %s NO es necesario

Ejemplo de Captura:

C

char nombre[50];

printf("Ingrese su nombre: ");

scanf("%s", nombre); // ¡Nota: NO se usa el &!

3. Restricciones y Riesgos de %s

Aunque %s es la forma más simple de leer texto, tiene limitaciones críticas en scanf() que el programador debe conocer desde ahora:

  • Problema con Espacios: %s solo lee caracteres hasta que encuentra el primer espacio en blanco. Si el usuario ingresa "Juan Pérez", scanf() solo capturará "Juan". La palabra Pérez queda en el buffer de entrada.

  • Riesgo de Desbordamiento (Buffer Overflow): %s no respeta el tamaño máximo del arreglo ([50] en el ejemplo). Si el usuario ingresa una cadena más larga que el espacio reservado, se produce un desbordamiento del buffer, sobrescribiendo la memoria adyacente y pudiendo causar fallos en el programa.

  • Mitigación del Riesgo: Para controlar el desbordamiento, se debe limitar la cantidad de caracteres a leer directamente en el especificador de formato. Si el arreglo es de 50, se lee un máximo de 49 para dejar espacio para el \0.

C

// Limita la lectura a 49 caracteres para evitar overflow.

scanf("%49s", nombre);

Nota: Para capturar frases completas con espacios y manejar la seguridad de las cadenas de manera robusta, se requerirán funciones más avanzadas (como fgets), que se verán en módulos posteriores.

Manejo de Errores Básicos de scanf

La función scanf() asume que el usuario ingresará los datos exactamente como se especifican (ej: un número entero para %d). Sin embargo, en el mundo real, los usuarios pueden cometer errores, como ingresar una letra cuando se espera un número. Es fundamental entender cómo reacciona scanf() ante estas fallas de validación.

Cómo Falla scanf()

scanf() intenta leer la entrada del buffer del teclado y convertirla al tipo de dato esperado por el especificador de formato.

  1. Fallo de Conversión: Si la entrada del usuario no coincide con el tipo de formato esperado (por ejemplo, el usuario escribe hola en lugar de 123 para %d), scanf() detiene la lectura inmediatamente.

  2. Devolución de Valor: scanf() devuelve un valor que indica cuántos elementos leyó con éxito.

    • Si todo sale bien, devuelve el número de variables que solicitaste (ej: 1 si pediste un %d).

    • Si hay un error de conversión, devuelve un número menor a lo esperado o 0.

  3. El Buffer Sucio: Lo más problemático es que el dato incorrecto (hola en nuestro ejemplo) permanece en el buffer de entrada. Si el programa intenta una lectura subsiguiente de datos, leerá ese dato erróneo en lugar de esperar una nueva entrada del usuario, provocando un ciclo de fallos.

Ejemplo de Falla

C

#include <stdio.h>

int main(void) {

int numero;

printf("Ingrese un numero entero: ");

// El valor devuelto por scanf se puede guardar

int elementos_leidos = scanf("%d", &numero);

// Si el usuario ingresa una letra, 'elementos_leidos' sera 0.

printf("scanf leyo %d elementos.\n", elementos_leidos);

printf("El valor de numero es: %d (Si es incorrecto, es un valor 'basura').\n", numero);

return 0;

}

Gestión Avanzada: La detección y corrección de estos errores (limpiar el buffer de entrada y solicitar el dato nuevamente) es un tema avanzado que requiere el uso de estructuras de control (while o if) y funciones específicas (como getchar()), y se abordará más adelante. Por ahora, basta con saber que la entrada incorrecta del usuario es una fuente común de errores en C.
