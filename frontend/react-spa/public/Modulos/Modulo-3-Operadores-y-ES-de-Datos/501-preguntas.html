📊 15 Ejercicios: Salida Estándar Formateada (printf)

Aquí tienes 15 ejercicios para repasar el Formateo Avanzado de la Salida con printf(), incluyendo el control de precisión, el ancho de campo, el uso de %c, %s y la tabulación.

Bloque 1: Múltiples Argumentos y Precisión Numérica

1) Múltiples Argumentos y Tipos

Imprime la edad (int) y la calificación promedio (float) de un estudiante en una sola línea.

Datos: edad = 21, promedio = 8.75

Output Esperado: El estudiante tiene 21 años y su promedio es 8.750000.

2) Formato de Moneda (%.2f)

Imprime un precio (float) asegurándote de que siempre muestre exactamente dos decimales para el formato de moneda.

Datos: costo = 12.9

Output Esperado: El costo es: $12.90

3) Redondeo por Precisión (%.0f)

Imprime un valor flotante limitando la precisión a cero decimales (%.0f). Observa que printf realiza un redondeo.

Datos: temperatura = 36.65

Output Esperado: Temperatura redondeada: 37

4) Especificadores Repetidos

Imprime el mismo número entero (int) dos veces en la misma línea, separándolos con una coma.

Datos: numero_base = 50

Output Esperado: El numero es 50, y otra vez 50.

5) Impresión de double con Precisión Alta

Imprime una constante de doble precisión (double) mostrando 6 decimales.

Datos: PI = 3.1415926535

Output Esperado: Valor de PI: 3.141593

Bloque 2: Ancho de Campo (Padding) y Alineación

6) Ancho de Campo para Enteros (%w.d)

Imprime un número entero en una columna que tenga un ancho total de 8 caracteres.

Datos: codigo = 123

Output Esperado: 123 (El 123 está precedido por 5 espacios).

7) Combinación de Ancho y Precisión (%w.nf)

Imprime un porcentaje (float) en una columna de 6 caracteres de ancho con un solo decimal.

Datos: porcentaje = 10.5

Output Esperado: 10.5 (El 10.5 está precedido por 2 espacios).

8) Alineación a la Izquierda para Texto (%-w.s)

Imprime una palabra (%s) en una columna de 12 caracteres, alineada a la izquierda (usando -).

Datos: producto = "Leche"

Output Esperado: Leche (La palabra Leche está seguida por 7 espacios).

9) Alineación a la Derecha de Texto (Impresión de ID)

Imprime un ID de usuario que debe ocupar un mínimo de 10 caracteres y alinearse a la derecha.

Datos: id_usuario = "USER45"

Output Esperado: USER45 (El ID está precedido por 4 espacios).

10) Formato de Tabla Simple (Encabezados)

Imprime un encabezado de tabla sencillo usando la secuencia de escape de tabulación (\t) para separar las columnas.

Output Esperado: ID\tNombre\tEstado (El compilador generará los espacios de tabulación)

Bloque 3: Caracteres, Cadenas y Estructuración

11) Impresión Secuencial de Caracteres (%c)

Imprime tres caracteres individuales, seguidos por un salto de línea (\n).

Datos: c1 = 'A', c2 = 'C', c3 = 'E'

Output Esperado: A C E

12) Uso de Código ASCII

Imprime un carácter utilizando su código ASCII entero (int). Usa el código 35 (que corresponde a #).

Datos: codigo_hash = 35

Output Esperado: El simbolo es: #

13) Impresión de Cadena con Limitación (%.ns)

Imprime una cadena de texto, limitando la salida a solo los primeros 7 caracteres (precisión de cadena).

Datos: frase = "Programacion"

Output Esperado: Program

14) Creación de una Fila de Tabla (Alineación Combinada)

Imprime una fila de datos que contenga un nombre (%-10s) y una edad (%5d), asegurando la alineación.

Datos: nombre = "Ana", edad = 22

Output Esperado: Ana | 22 (El nombre tiene 7 espacios de relleno y la edad 3).

15) Formateo de Recibo (Mixto)

Imprime el costo total de una compra (float) con 2 decimales y el nombre del cajero (%s) en una salida estructurada.

Datos: total = 245.89, cajero = "Luis"

Output Esperado: TOTAL: $245.89. Atendido por Luis

Respuestas y Código Fuente

C

#include <stdio.h>

int main(void) {

// Variables para ejercicios

int edad = 21, numero_base = 50, codigo = 123, codigo_hash = 35, num_A = 10, num_B = 20;

float promedio = 8.75f, costo = 12.9f, temperatura = 36.65f, porcentaje = 10.5f, total = 245.89f;

double PI = 3.1415926535;

char c1 = 'A', c2 = 'C', c3 = 'E';

char producto[] = "Leche";

char id_usuario[] = "USER45";

char frase[] = "Programacion";

char nombre[] = "Ana";

char cajero[] = "Luis";

printf("--- Soluciones de Ejercicios ---\n");

// 1) Múltiples Argumentos y Tipos

printf("1) Output Esperado: El estudiante tiene %d años y su promedio es %f.\n", edad, promedio);

// 2) Formato de Moneda (%.2f)

printf("2) Output Esperado: El costo es: $%.2f\n", costo);

// 3) Redondeo por Precisión (%.0f)

printf("3) Output Esperado: Temperatura redondeada: %.0f\n", temperatura);

// 4) Especificadores Repetidos

printf("4) Output Esperado: El numero es %d, y otra vez %d.\n", numero_base, numero_base);

// 5) Impresión de double con Precisión Alta

printf("5) Output Esperado: Valor de PI: %.6f\n", PI);

// 6) Ancho de Campo para Enteros (%w.d)

printf("6) Output Esperado: |%8d|\n", codigo);

// 7) Combinación de Ancho y Precisión (%w.nf)

printf("7) Output Esperado: |%6.1f|\n", porcentaje);

// 8) Alineación a la Izquierda para Texto (%-w.s)

printf("8) Output Esperado: |%-12s|\n", producto);

// 9) Alineación a la Derecha de Texto (Impresión de ID)

printf("9) Output Esperado: |%10s|\n", id_usuario);

// 10) Formato de Tabla Simple (Encabezados)

printf("10) Output Esperado: ID\tNombre\tEstado\n");

// 11) Impresión Secuencial de Caracteres (%c)

printf("11) Output Esperado: %c %c %c\n", c1, c2, c3);

// 12) Uso de Código ASCII

printf("12) Output Esperado: El simbolo es: %c\n", codigo_hash);

// 13) Impresión de Cadena con Limitación (%.ns)

printf("13) Output Esperado: %.7s\n", frase);

// 14) Creación de una Fila de Tabla (Alineación Combinada)

printf("14) Output Esperado: %-10s | %5d\n", nombre, edad);

// 15) Formateo de Recibo (Mixto)

printf("15) Output Esperado: TOTAL: $%.2f. Atendido por %s\n", total, cajero);

return 0;

}
