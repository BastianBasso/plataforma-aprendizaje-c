🚀 Proyecto Final del Módulo 3: Simulador de Finanzas Personales (I-P-O Extendido)

Este proyecto integrará todos los conocimientos adquiridos en el Módulo 3: Operadores y E/S de Datos (Input, Procesamiento, Output formateado, Precedencia y Operadores).

El objetivo es crear un programa que simule el cálculo del Flujo de Caja Mensual de una persona, aplicando impuestos, descuentos y mostrando el resultado de forma clara y profesional.

Objetivo del Proyecto

Crear un programa completo que solicite los ingresos brutos y los gastos fijos de un usuario, aplique un impuesto y un ahorro obligatorio, y determine su Saldo Neto Disponible.

Estructura del Programa (Ciclo I-P-O)

El proyecto se dividirá estrictamente en las tres fases del modelo I-P-O:

  1. Input: Captura de Ingresos Brutos y Gastos Fijos (float).

  2. Procesamiento: Aplicación de fórmulas de cálculo (Impuesto, Ahorro) usando operadores aritméticos, relacionales y precedencia.

  3. Output: Presentación del resultado como una tabla financiera legible, utilizando control de precisión (.2f) y ancho de campo (%w.nf).

Requisitos de Datos y Constantes

Nombre Tipo de Dato Valor / Uso
Ingreso Bruto float Dato de Input del usuario.
Gasto Fijo float Dato de Input del usuario.
TASA_IMPUESTO const float Fijo: $0.15$ (15% de impuesto sobre el ingreso).
TASA_AHORRO const float Fijo: $0.10$ (10% de ahorro obligatorio sobre el ingreso neto).

CÓDIGO FUENTE DEL PROYECTO

C

#include <stdio.h>

// Definición de constantes para el procesamiento

#define TASA_IMPUESTO 0.15f

#define TASA_AHORRO 0.10f

int main(void) {

// Variables de Input (Fase 1)

float ingreso_bruto;

float gasto_fijo;

// Variables de Procesamiento (Fase 2)

float impuesto_calculado;

float ingreso_neto_inicial;

float ahorro_obligatorio;

float saldo_neto_disponible;

int tiene_superavit; // Resultado lógico (1 o 0)

// ==========================================================

// FASE 1: INPUT (Captura de Datos)

// ==========================================================

printf("--- 💰 Simulador de Flujo de Caja Mensual ---\n\n");

// Captura del Ingreso Bruto (Input 1)

printf("1. Ingrese su ingreso mensual BRUTO (antes de impuestos): $");

scanf("%f", &ingreso_bruto);

// Captura de Gastos Fijos (Input 2)

printf("2. Ingrese el total de gastos fijos (alquiler, servicios, etc.): $");

scanf("%f", &gasto_fijo);

// Verificacion de exito logico (Uso del operador relacional)

int input_correcto = (ingreso_bruto > 0 && gasto_fijo >= 0);

// Si el input inicial no es logico, simplemente terminamos

if (!input_correcto) {

printf("\n[ERROR] Los ingresos deben ser positivos. Finalizando programa.\n");

return 1;

}

// ==========================================================

// FASE 2: PROCESAMIENTO (Cálculos Financieros)

// ==========================================================

// Cálculo 1: Impuesto (Uso de Aritmético y Asignación)

// NOTA: Se aplica la precedencia natural: * se calcula antes de -

impuesto_calculado = ingreso_bruto * TASA_IMPUESTO;

ingreso_neto_inicial = ingreso_bruto - impuesto_calculado;

// Cálculo 2: Ahorro Obligatorio (sobre el ingreso neto)

ahorro_obligatorio = ingreso_neto_inicial * TASA_AHORRO;

// Cálculo 3: Saldo Disponible Final

saldo_neto_disponible = ingreso_neto_inicial - ahorro_obligatorio - gasto_fijo;

// Cálculo 4: Resultado Lógico (Superávit vs. Déficit)

// Uso del operador relacional para generar 1 (Superávit) o 0 (Déficit)

tiene_superavit = (saldo_neto_disponible >= 0);

// ==========================================================

// FASE 3: OUTPUT (Presentación Formateada)

// ==========================================================

printf("\n\n--- 📊 REPORTE DE FLUJO DE CAJA MENSUAL ---\n");

printf("===========================================\n");

// 1. Mostrar Ingresos y Deducciones

// Uso de %-30s para alinear texto a la izquierda en una columna de 30

printf("%-30s | %10.2f\n", "INGRESOS BRUTOS", ingreso_bruto);

printf("-------------------------------------------\n");

// Detalle de Deducciones

printf("%-30s |-%9.2f\n", "(-) Impuesto (15%)", impuesto_calculado);

printf("%-30s | %10.2f\n", "INGRESO NETO DESPUES DE IMPUESTOS", ingreso_neto_inicial);

printf("-------------------------------------------\n");

// Detalle de Ahorro y Gastos

printf("%-30s |-%9.2f\n", "(-) Ahorro Obligatorio (10%)", ahorro_obligatorio);

printf("%-30s |-%9.2f\n", "(-) Gastos Fijos Mensuales", gasto_fijo);

printf("===========================================\n");

// 2. Mostrar el Saldo Final con Formato Condicional

// El ancho de campo (10.2f) garantiza la alineación perfecta

printf("%-30s | %10.2f\n", "SALDO NETO DISPONIBLE", saldo_neto_disponible);

printf("===========================================\n");

// 3. Mostrar el Resultado Lógico con Texto Descriptivo

printf("ESTADO FINANCIERO: ");

// Uso de operador relacional (== 1) y condicional (?:) para un output legible

if (tiene_superavit == 1) {

printf("¡SUPERÁVIT! El saldo es positivo.\n");

} else {

printf("DÉFICIT. El saldo es negativo.\n");

}

printf("-------------------------------------------\n");

return 0;

}
