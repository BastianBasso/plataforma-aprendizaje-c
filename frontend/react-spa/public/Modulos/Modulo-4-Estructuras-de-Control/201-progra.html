💻 15 Ejercicios: Estructuras Condicionales (if / if-else)

Bloque 1: Condicional Simple (if)

1) Verificación de Cero

Pide un número entero. Usa un if simple para imprimir "¡El número es cero!" solo si el número es igual a $0$.

Input de Ejemplo: 0

Output Esperado: ¡El número es cero!

2) Valor Positivo (Uso de > )

Pide un número entero (int). Usa un if para imprimir "El valor es positivo" solo si es estrictamente mayor que $0$.

Input de Ejemplo: 50

Output Esperado: El valor es positivo

3) Mensaje de Alerta (Uso de != )

Pide el nivel de batería (int, de 0 a 100). Usa un if simple para mostrar "¡Batería NO está al 100%!" solo si el nivel es diferente de $100$.

Input de Ejemplo: 95

Output Esperado: ¡Batería NO está al 100%!

4) Descuento Simple

Pide el total de una compra (float). Usa un if para aplicar un descuento del $10\%$ y mostrar el nuevo total solo si la compra supera los $200$ (sin incluir $200$).

Input de Ejemplo: 250.0

Output Esperado: Total con descuento (10%): 225.00

5) Verificación de Carácter Específico

Pide al usuario que ingrese una letra (char). Usa un if para imprimir "¡Es la letra 'A'!" solo si la letra ingresada es igual a 'A'.

Input de Ejemplo: A

Output Esperado: ¡Es la letra 'A'!

Bloque 2: Condicional Doble (if-else)

6) Verificador de Mayoría de Edad

Pide la edad (int). Usa if-else para determinar si la persona es "Mayor de edad" ($\ge 18$) o "Menor de edad".

Input de Ejemplo: 17

Output Esperado: Menor de edad.

7) Par o Impar (Uso de % )

Pide un número entero. Usa el operador módulo (%) y if-else para imprimir si el número es "Par" o "Impar".

Input de Ejemplo: 13

Output Esperado: El numero es Impar.

8) Evaluación de Calificación

Pide una calificación (float). Usa if-else para imprimir "Aprobado" (si $\ge 7.0$) o "Reprobado" (si $< 7.0$).

Input de Ejemplo: 8.5

Output Esperado: Aprobado.

9) Comprobación de Acceso

Pide un código de acceso (int). Si el código es igual a $1234$, imprime "Acceso Concedido". De lo contrario, imprime "Acceso Denegado".

Input de Ejemplo: 5000

Output Esperado: Acceso Denegado.

10) Saldo de Cuenta Bancaria

Pide el saldo actual (float). Usa if-else para informar si la cuenta tiene "Fondos Positivos" ($\ge 0$) o "Fondos Negativos".

Input de Ejemplo: -25.50

Output Esperado: Fondos Negativos.

Bloque 3: Condiciones Lógicas y Avanzadas

11) Rango de Temperatura (Uso de && )

Pide una temperatura (int). Usa un if con el operador && para imprimir "Temperatura ideal" solo si la temperatura está entre 20 y 30 grados (incluyendo ambos extremos).

Input de Ejemplo: 25

Output Esperado: Temperatura ideal.

12) Acceso por Permiso (Uso de || )

Pide el nivel de usuario (int, donde $1$ es Admin y $0$ es Invitado) y si el usuario es "VIP" (char, 'S' o 'N'). Usa if con el operador || para imprimir "Acceso de Alto Nivel" solo si es Admin ($\text{nivel} = 1$) O es VIP ($\text{VIP} = \text{'S'}$).

Input de Ejemplo: 0 (Nivel), S (VIP)

Output Esperado: Acceso de Alto Nivel

13) Negación Lógica (Uso de ! )

Pide un valor booleano (int, $0$ o $1$). Usa un if con el operador ! para imprimir "El valor es Falso" solo si el valor ingresado es $0$.

Input de Ejemplo: 0

Output Esperado: El valor es Falso

14) Condición Compuesta y Aritmética

Pide dos números enteros, A y B. Usa if-else para determinar si la suma de A y B es mayor que 10 O el producto de A y B es igual a 20. Imprime el resultado.

Input de Ejemplo: A=2, B=5

Output Esperado: La suma es menor que 10 y el producto no es 20.

15) Validación de Entrada con if Simple (Sintaxis Compacta)

Pide un número. Usa el operador if de una sola línea (sin llaves) para imprimir "Número válido." solo si el número es mayor a $100$.

Input de Ejemplo: 101

Output Esperado: Número válido.

Respuestas y Código Fuente

C

#include <stdio.h>

int main(void) {

// Variables para ejercicios

int num, bateria, edad, codigo, temp, nivel_usuario, valor_bool, num_A, num_B;

char letra, es_vip;

float compra, calificacion, saldo, total_descuento, nuevo_total;

printf("--- Soluciones de Ejercicios de Estructuras Condicionales ---\n");

// 1) Verificación de Cero (if simple)

printf("\n1) Ingrese un entero (0 para probar): ");

scanf("%d", &num);

if (num == 0) {

printf("Output Esperado: ¡El número es cero!\n");

}

// 2) Valor Positivo (if simple con >)

printf("\n2) Ingrese un entero: ");

scanf("%d", &num);

if (num > 0) {

printf("Output Esperado: El valor es positivo\n");

}

// 3) Mensaje de Alerta (if simple con !=)

printf("\n3) Nivel de bateria (0-100): ");

scanf("%d", &bateria);

if (bateria != 100) {

printf("Output Esperado: ¡Batería NO está al 100%%!\n");

}

// 4) Descuento Simple (if simple y aritmetica)

printf("\n4) Total de la compra: $");

scanf("%f", &compra);

if (compra > 200.0f) {

total_descuento = compra * 0.10f;

nuevo_total = compra - total_descuento;

printf("Output Esperado: Total con descuento (10%%): %.2f\n", nuevo_total);

}

// 5) Verificación de Carácter Específico (if simple con char)

printf("\n5) Ingrese una letra: ");

scanf(" %c", &letra);

if (letra == 'A') {

printf("Output Esperado: ¡Es la letra 'A'!\n");

}

// 6) Verificador de Mayoría de Edad (if-else)

printf("\n6) Ingrese edad: ");

scanf("%d", &edad);

if (edad >= 18) {

printf("Output Esperado: Mayor de edad.\n");

} else {

printf("Output Esperado: Menor de edad.\n");

}

// 7) Par o Impar (if-else con %)

printf("\n7) Ingrese un numero para par/impar: ");

scanf("%d", &num);

if (num % 2 == 0) {

printf("Output Esperado: El numero es Par.\n");

} else {

printf("Output Esperado: El numero es Impar.\n");

}

// 8) Evaluación de Calificación (if-else)

printf("\n8) Ingrese calificacion (float): ");

scanf("%f", &calificacion);

if (calificacion >= 7.0f) {

printf("Output Esperado: Aprobado.\n");

} else {

printf("Output Esperado: Reprobado.\n");

}

// 9) Comprobación de Acceso (if-else)

printf("\n9) Ingrese codigo de acceso: ");

scanf("%d", &codigo);

if (codigo == 1234) {

printf("Output Esperado: Acceso Concedido.\n");

} else {

printf("Output Esperado: Acceso Denegado.\n");

}

// 10) Saldo de Cuenta Bancaria (if-else)

printf("\n10) Ingrese saldo actual (float): $");

scanf("%f", &saldo);

if (saldo >= 0) {

printf("Output Esperado: Fondos Positivos.\n");

} else {

printf("Output Esperado: Fondos Negativos.\n");

}

// 11) Rango de Temperatura (if con &&)

printf("\n11) Temperatura (int): ");

scanf("%d", &temp);

if (temp >= 20 && temp <= 30) {

printf("Output Esperado: Temperatura ideal.\n");

}

// 12) Acceso por Permiso (if con ||)

printf("\n12) Nivel usuario (1/0) y VIP ('S'/'N'): ");

scanf("%d %c", &nivel_usuario, &es_vip);

if (nivel_usuario == 1 || es_vip == 'S') {

printf("Output Esperado: Acceso de Alto Nivel\n");

}

// 13) Negación Lógica (if con !)

printf("\n13) Valor booleano (0 o 1): ");

scanf("%d", &valor_bool);

if (!valor_bool) { // Es True (distinto de 0) si valor_bool es 0.

printf("Output Esperado: El valor es Falso\n");

}

// 14) Condición Compuesta y Aritmética (if-else con ||)

printf("\n14) Dos numeros A y B: ");

scanf("%d %d", &num_A, &num_B);

if ((num_A + num_B > 10) || (num_A * num_B == 20)) {

printf("Output Esperado: Condicion compuesta Verdadera.\n");

} else {

printf("Output Esperado: La suma es menor que 10 y el producto no es 20.\n");

}

// 15) Validación de Entrada con if Simple (Sintaxis Compacta)

printf("\n15) Ingrese un numero: ");

scanf("%d", &num);

if (num > 100)

printf("Output Esperado: Número válido.\n");

return 0;

}
