Resumen Módulo: Estructuras de Control de Flujo (Decisión y Repetición)

Este módulo se centró en la esencia de la programación: el Control de Flujo. Aprendiste a desviar la ejecución lineal del programa para tomar decisiones (estructuras condicionales) y para ejecutar tareas repetitivas (estructuras de bucle), permitiendo la creación de lógica compleja e interactiva.

1. El Control de Flujo: Desviando la Ejecución Lineal

Concepto Flujo de Ejecución Herramientas en C
Lineal (Secuencial) Las instrucciones se ejecutan una tras otra en el orden en que fueron escritas. Código base sin if ni bucles.
Estructurado (Controlado) El programa puede saltar, decidir qué código ejecutar o repetir bloques de código. if, else, switch, for, while, do-while, break, continue.

2. Estructuras de Decisión (Condicionales)

Estas estructuras permiten que el programa elija qué camino seguir. Se basan en la evaluación de expresiones relacionales (<, >) y lógicas (&&, ||, !).

Estructura Propósito Condición Uso Clave
if / if-else Tomar una decisión binaria (dos caminos: si se cumple o no se cumple). Simple Validar una única lógica o un camino alternativo.
else if Evaluar una secuencia de condiciones exclusivas. Múltiple y secuencial Clasificar notas, determinar rangos, crear cadenas de decisión donde solo una opción es posible.
switch Ejecutar un bloque de código basado en la coincidencia exacta de un valor (típicamente entero o carácter). Único Valor Implementación de menús, selección de días de la semana, manejo de códigos de error. Requiere break en cada case para evitar el fall-through.
Anidamiento (if anidado) Colocar una estructura condicional dentro de otra. Compleja Refinar una condición previa (ej: Si es administrador Y su contraseña es correcta).

3. Estructuras de Repetición (Bucles)

Estas estructuras permiten ejecutar un bloque de código repetidamente hasta que una condición de terminación se cumpla.

Estructura Tipo de Repetición Evaluación de Condición Ejecución Mínima
for Por Contador Fijo Al inicio (antes de cada iteración). Cero (si la condición inicial es falsa).
while Condicional Previo Al inicio. Ideal para patrones de Centinela (se repite hasta encontrar un valor específico, ej: $0$). Cero (si la condición inicial es falsa).
do-while Condicional Posterior Al final de la iteración. Una vez (garantizada, incluso si la condición es falsa). Ideal para Menús interactivos.

4. Control Fino de Bucles (break y continue)

Estas sentencias se utilizan dentro de los bucles para modificar el flujo de repetición de forma inmediata.

Sentencia Propósito Mecanismo Ejemplo de Uso
break Terminación Forzada. Sale inmediatamente del bucle (for, while, do-while) o switch más interno, ignorando la condición principal. Límites de intentos, búsqueda de un elemento (detener la búsqueda al encontrarlo), salir de un while(1).
continue Salto de Iteración. Omite el resto del código en la iteración actual y pasa inmediatamente a la siguiente vuelta del bucle. Filtrado de datos (ej: ignorar o saltar el procesamiento de números pares o valores inválidos).
