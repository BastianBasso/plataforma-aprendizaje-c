Cuestionario: Historia, Propósito y Aplicaciones del Lenguaje C

Preguntas de Alternativas

1. ¿Quién es reconocido como el creador principal del Lenguaje C en los Laboratorios Bell a principios de la década de 1970?

A. Ken Thompson

B. Bjarne Stroustrup

C. Dennis Ritchie

D. Linus Torvalds

2. ¿Cuál fue el propósito fundamental e inmediato que llevó al desarrollo inicial del Lenguaje C?

A. Crear un lenguaje de programación orientado a objetos.

B. Desarrollar el firmware para microcontroladores y dispositivos IoT.

C. Reescribir el núcleo (kernel) del sistema operativo UNIX.

D. Simplificar la programación de interfaces de usuario gráficas (GUI).

3. ¿Cómo se clasifica el Lenguaje C en términos de su nivel, dado que combina control de hardware con estructuras legibles?

A. Lenguaje de muy bajo nivel (Ensamblador).

B. Lenguaje de nivel medio.

C. Lenguaje de nivel máquina (Binario).

D. Lenguaje de muy alto nivel (Python o Java).

4. ¿Cuál fue la limitación principal del Lenguaje Ensamblador que C superó para reescribir UNIX y ganar popularidad?

A. Era demasiado rápido para ser controlado.

B. No podía manipular la memoria RAM directamente.

C. Su falta de portabilidad entre diferentes arquitecturas de hardware.

D. Su dificultad para trabajar con el sistema de archivos.

5. ¿Qué característica clave que no poseía el Lenguaje B añadió Dennis Ritchie a C?

A. Estructuras de control avanzadas.

B. Programación paralela.

C. La manipulación eficiente de tipos de datos.

D. Soporte para interfaces de usuario gráficas (GUI).

6. ¿Cuál es el propósito principal de la estandarización de C, como la realizada por ANSI C (C89/C90)?

A. Añadir la programación orientada a objetos (POO) al lenguaje.

B. Garantizar que el código C funcione de manera consistente en diferentes máquinas y compiladores.

C. Limitar el uso de C solo a los sistemas operativos.

D. Mejorar la velocidad de ejecución de los programas C en un 50%.

7. El alto rendimiento y la eficiencia de recursos de C se deben principalmente a:

A. Su uso de una máquina virtual (VM) para la ejecución de código.

B. Su cercanía al hardware y el control manual sobre la memoria.

C. Ser un lenguaje de programación completamente interpretado.

D. Su dependencia total de un framework externo de optimización.

8. En el área de Videojuegos de alto rendimiento, el conocimiento de C es fundamental porque los motores gráficos y de física (que usan C++) heredan de C:

A. La programación orientada a objetos.

B. La eficiencia y el control de bajo nivel sobre la memoria.

C. La facilidad de codificación de la interfaz gráfica.

D. La gestión automática de memoria (recolección de basura).

9. Además de los Sistemas Operativos, C es el lenguaje predilecto para los Sistemas Embebidos y firmware (IoT) debido a:

A. Su sintaxis es la más moderna disponible.

B. Su capacidad para manipular directamente el hardware y su eficiencia en el uso de recursos limitados.

C. Su dependencia de un garbage collector para limpiar la memoria automáticamente.

D. Es el único lenguaje que puede compilarse para estos sistemas.

10. ¿Cuál de las siguientes infraestructuras de software se construyó inicialmente en C para garantizar su velocidad y eficiencia?

A. Las interfaces gráficas de Microsoft Office.

B. La lógica de negocio de las aplicaciones móviles de Android.

C. Los intérpretes principales de lenguajes como Python y PHP.

D. El software de diseño web basado en plantillas.

Respuestas Correctas

  1. C

  2. C

  3. B

  4. C

  5. C

  6. B

  7. B

  8. B

  9. B

  10. C
