Cuestionario: Estructura Básica de un Programa C (La Función main)

Preguntas de Alternativas

1. ¿Cuál es la extensión de archivo estándar utilizada para los archivos de código fuente escritos en Lenguaje C?

A. .cpp

B. .exe

C. .h

D. .c

2. La directiva del preprocesador #include <stdio.h> es necesaria principalmente porque proporciona funciones para:

A. Realizar operaciones matemáticas avanzadas.

B. Gestionar la memoria RAM del sistema.

C. La interacción básica de Entrada y Salida (como printf() y scanf()).

D. Definir estructuras de datos complejas.

3. ¿Cuál es el rol de la función main() dentro de un programa C?

A. Es una función opcional que solo se usa para depuración.

B. Es el punto de entrada y salida obligatorio, donde el sistema operativo comienza la ejecución.

C. Es la función responsable de gestionar la memoria dinámica.

D. Se encarga de incluir todas las librerías necesarias.

4. En la declaración de la función principal, int main(void), ¿qué representa el prefijo int?

A. Indica que la función solo puede recibir argumentos enteros.

B. Es la abreviatura de "inicio".

C. El tipo de dato (entero) que se devuelve al sistema operativo como código de estado.

D. El número máximo de sentencias que puede contener la función.

5. ¿Qué par de símbolos se utiliza para definir el Bloque de Código o el cuerpo de la función main()?

A. () (Paréntesis)

B. [] (Corchetes)

C. <> (Símbolos de menor y mayor)

D. {} (Llaves)

6. ¿Qué símbolo debe usarse obligatoriamente para terminar una sentencia (una instrucción completa) dentro de un bloque de código C?

A. Dos puntos :

B. Coma ,

C. Barra /

D. Punto y coma ;

7. ¿Cuál es el significado convencional de la sentencia return 0; al final de la función main()?

A. El programa se detiene debido a un error de Enlazado.

B. El programa ha finalizado su ejecución de manera exitosa.

C. El programa debe reiniciarse inmediatamente.

D. La función main() devuelve una dirección de memoria.

8. Si un programa C finaliza retornando un valor distinto de cero (ej. return 1;), ¿qué convención se utiliza para comunicar este estado al sistema operativo?

A. Que el programa fue más rápido de lo esperado.

B. Que ocurrió un fallo o un error durante su ejecución.

C. Que el código fuente necesita más comentarios.

D. Que el código no pudo ser compilado.

9. ¿Cuál es la principal característica de los comentarios (// o /* ... */) respecto al proceso de compilación?

A. Se convierten en código máquina para optimizar el rendimiento.

B. El Compilador los utiliza para verificar errores de Enlazado.

C. Son ignorados y eliminados completamente por el Preprocesador, sin afectar el ejecutable.

D. Deben ir siempre al principio del archivo fuente.

10. Si un proyecto de C es grande y complejo, ¿por qué es recomendable organizarlo en múltiples archivos fuente (.c) en lugar de uno solo?

A. El compilador solo puede procesar archivos pequeños.

B. Para mejorar la modularidad, facilitar el mantenimiento y la colaboración en equipo.

C. Es una obligación del estándar ANSI C.

D. El proceso de Preprocesamiento solo funciona con un archivo a la vez.

Respuestas Correctas

  1. D

  2. C

  3. B

  4. C

  5. D

  6. D

  7. B

  8. B

  9. C

  10. B
