2. Ejercicio de Código Práctico: Perfil de Usuario

Escribe un programa C completo que utilice todos los elementos clave que has aprendido hasta ahora.

Requisitos del Código:

  1. Debe incluir la librería stdio.h.

  2. Debe contener la estructura int main(void).

  3. Utiliza múltiples llamadas a printf() para mostrar el siguiente perfil de usuario en la consola, asegurándote de que cada pieza de información aparezca en una línea separada y con una tabulación entre la etiqueta y el valor.

Salida Deseada:

--- PERFIL DE USUARIO ---

Nombre: Juan Pérez

Edad: 30 años

Lenguaje: C

-------------------------

Solución del Ejercicio:

C

#include <stdio.h>

int main(void) {

// Encabezado del perfil con saltos de línea

printf("--- PERFIL DE USUARIO ---\n");

// Información con tabulación (\t) para alinear

printf("Nombre:\t\tJuan Pérez\n");

printf("Edad:\t\t30 años\n");

printf("Lenguaje:\tC\n");

// Cierre del perfil

printf("-------------------------\n");

return 0;

}
